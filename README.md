# hitesh-engineering

Source for https://hiteshpranav267.github.io/hitesh-engineering/ — Hitesh Pranav Reddy's site: RTL design and verification projects, a CV, and handwritten ECE notes. The home page is an illustrated study room where each object opens a page; `/list/` is the same site as a plain list.

## Run it

```
npm install
npm run dev            # http://localhost:3000/hitesh-engineering/
npm run build          # static export to out/, then the Pagefind index
npm run serve          # serve out/ under the basePath on :4173
```

The site deploys to GitHub Pages from `main` via `.github/workflows/deploy.yml`.

## Where things live

| Path | What |
|---|---|
| `content/profile.yaml`, `experience.yaml`, `skills.yaml` | Facts, each tagged with its source line in `private/main.md` |
| `content/projects/*.mdx` | One file per project: frontmatter (stack, scope, metrics, images) and fact bullets |
| `content/notes.yaml` | Generated by `scripts/notes/build.py`; `topics`, `semester` and `unit` are safe to hand-edit |
| `content/scene.json` | Room objects: label, target page, parallax layer, landscape and portrait placement, Tab order |
| `content/room/` | The real RISC-V VCD behind the laptop screen, and the JSON drawn from it |
| `components/room/` | Room art (flat SVG) and behaviour (GSAP camera, parallax, hotspots) |
| `app/` | Routes: `/` (room), `/list`, `/projects`, `/notes`, `/desk`, `/experience`, `/cv`, `/about`, `/contact`, `/field-notes` |
| `private/` | Gitignored: `main.md`, note PDF sources, assets, the render cache, TODO-CONFIRM |

## Notes pipeline

```
python -m venv scripts/notes/.venv
scripts/notes/.venv/Scripts/pip install pymupdf "pyvips[binary]" pyyaml
scripts/notes/.venv/Scripts/python scripts/notes/build.py        # all subjects
scripts/notes/.venv/Scripts/python scripts/notes/build.py --only dsp
```

It reads `private/notes/**/*.pdf` with `private/notes/_seed.yaml`, and writes `content/notes.yaml`, `public/notes-covers/`, and per-page thumbnails plus deep-zoom desk tiles in the gitignored `public/notes-dev/`. `scripts/notes/upload.sh` copies PDFs and tiles to Cloudflare R2; it only runs when called. After upload, set `NEXT_PUBLIC_NOTES_PDF_BASE` and `NEXT_PUBLIC_NOTES_ASSETS_BASE` for the Pages build.

## Checks

`node scripts/claims.mjs` maps every factual claim on the site to its source and checks it against `private/main.md`, writing `private/CLAIMS.md`.
