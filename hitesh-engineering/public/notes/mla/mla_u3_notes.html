8.1

Introduction

In previous chapters, we focused on parametric methods where we assumed the data was drawn from a known probability distribution (like a Gaussian). In such cases, the problem reduces to estimating a small number of parameters. However, if these assumptions are incorrect, we incur significant errors.

✦ The Nonparametric Approach
In nonparametric estimation, we make no a priori assumptions about the functional form of the underlying density. Instead, we assume that similar inputs have similar outputs. The data "speaks for itself."

Parametric vs. Nonparametric

Parametric
  • Assumes a global model valid for the entire input space.
  • Complexity is fixed (e.g., \(O(d)\) or \(O(d^2)\) parameters).
  • Eager Learning: Computes the model during training; discards training data after.
Nonparametric
  • Uses local models estimated as needed for specific query points.
  • Complexity depends on the size of the training set \(N\).
  • Lazy Learning: Postpones computation until a test instance is provided.

Complexity & Data Requirements

Nonparametric methods are often called memory-based or instance-based learning because they store the training instances in a lookup table and interpolate from them.

  • Space Complexity: \(O(N)\) — All training instances must be stored in memory.
  • Time Complexity (Query): \(O(N)\) — For every test input, we must search the entire dataset to find similar instances.
  • The "Lazy" Trade-off: While they require no training time, the increased need for memory and computation during prediction is their primary disadvantage.
Why use it?
It is ideal when the dataset is large and the underlying distribution is complex or multi-modal, making it impossible to fit a simple parametric model like a single Gaussian.
8.2

Nonparametric Density Estimation

The goal is to estimate an unknown probability density \(p(x)\) from a sample \(\mathcal{X} = \{x^1, \dots, x^N\}\). We start by considering the Cumulative Distribution Function (CDF).

\[ \hat{F}(x) = \frac{\#\{x^t \leq x\}}{N} \] → The proportion of sample points less than or equal to x.

The density function is the derivative of the CDF. In a small interval \(h\), we assume instances are "close enough" to estimate the density:

\[ \hat{p}(x) = \frac{1}{h} \left[ \hat{F}(x+h) - \hat{F}(x) \right] = \frac{1}{Nh} \#\{x^t \in [x, x+h]\} \]
Interactive Density Estimation
Data Points Estimated Density \(\hat{p}(x)\)
The Smoothing Parameter (h)
The parameter \(h\) (window/bin width) controls the bias-variance trade-off:
  • Small \(h\): High variance. Spiky estimate that overfits noise.
  • Large \(h\): High bias. Overly smooth estim

    8.2.1 Histogram Estimator

    The oldest and most popular method. The input space is divided into equal-sized intervals called bins. Once the bin estimates are calculated, this is the only nonparametric method that does not require retaining the training set, saving $O(N)$ space.

    \[ \hat{p}(x) = \frac{\#\{x^t \text{ in the same bin as } x\}}{Nh} \]
    The Bin Width (h) Effect
    • Small \(h\): Spiky estimate (High Variance).
    • Large \(h\): Smooth estimate (High Bias).
    The estimate is 0 if no instance falls in a bin, leading to sharp discontinuities.

    Naive Estimator (Origin-Free)

    To eliminate the dependency on the bin origin, the naive estimator centers the window at \(x\). It treats each \(x^t\) as having a symmetric region of influence of size \(h\).

    \[ \hat{p}(x) = \frac{1}{Nh} \sum_{t=1}^N w\left(\frac{x - x^t}{h}\right) \] Where \(w(u)\) is a "hard" weight function: \[ w(u) = \begin{cases} 1 & \text{if } |u| < 1/2 \\ 0 & \text{otherwise} \end{cases} \]

    8.2.2 Kernel Estimator (Parzen Window)

    The Naive estimator is discontinuous because of its "hard" weight function. The Kernel estimator replaces this with a smooth Kernel Function K(·). The resulting estimate is the sum of "bumps" centered at training points.

    \[ \hat{p}(x) = \frac{1}{Nh} \sum_{t=1}^N K\left(\frac{x - x^t}{h}\right) \]
    ✦ Property: Continuity Inheritance
    The estimator \(\hat{p}(x)\) inherits all continuity and differentiability properties of the kernel \(K(\cdot)\). If \(K(\cdot)\) is Gaussian (which is smooth and has all derivatives), then \(\hat{p}(x)\) will also be perfectly smooth.

    For a valid density, \(K(\cdot)\) must be non-negative and integrate to 1.

    8.2.3 k-Nearest Neighbor (k-NN) Estimator

    Unlike the kernel estimator which fixes the volume \(h\), k-NN fixes the number of observations \(k\) and lets the volume vary. In high-density regions, the window is small; in sparse regions, it expands.

    \[ \hat{p}(x) = \frac{k}{2N d_k(x)} \] → \(d_k(x)\) is the distance from \(x\) to its \(k\)-th nearest neighbor.
    Exam Critical: Why k-NN is not a true PDF?
    1. Integration: It is not a legitimate density function because it integrates to \(\infty\), not 1.
    2. Discontinuities: Its derivative is discontinuous at every \(x_{(j)}\) (the order statistics of the sample).

    Adaptive Kernel Smoothing

    To get a smoother result while retaining the adaptive nature of k-NN, we use an adaptive smoothing parameter \(h = d_k(x)\) within a kernel function:

    \[ \hat{p}(x) = \frac{1}{N d_k(x)} \sum_{t=1}^N K\left(\frac{x - x^t}{d_k(x)}\right) \]
strong>adaptive smoothing parameter \(h = d_k(x)\).

8.3

Generalization to Multivariate Data

For \(d\)-dimensional data (vectors \(\mathbf{x}\)), density estimators must be extended by scaling the volume \(V\) by \(h^d\).

⚠ The Curse of Dimensionality
In high-dimensional spaces, the concept of "closeness" becomes blurry.
Example: In an 8-dimensional space with 10 bins per dimension, there are \(10^8\) total bins. Unless the dataset is massive, most bins will be empty, leading to zero-density estimates everywhere.

Multivariate Kernel Estimator

\[ \hat{p}(\mathbf{x}) = \frac{1}{Nh^d} \sum_{t=1}^N K\left(\frac{\mathbf{x} - \mathbf{x}^t}{h}\right) \]

The standard Euclidean distance assumes all dimensions are scaled equally. If features have different scales or are correlated, we use the Mahalanobis Distance with sample covariance \(\mathbf{S}\):

\[ K(\mathbf{x}, \mathbf{x}^t) = \frac{1}{(2\pi)^{d/2} |\mathbf{S}|^{1/2}} \exp\left[-\frac{1}{2h^2} (\mathbf{x} - \mathbf{x}^t)^T \mathbf{S}^{-1} (\mathbf{x} - \mathbf{x}^t)\right] \]

Multivariate k-NN Estimator

\[ \hat{p}(\mathbf{x}) = \frac{k}{N V_k(\mathbf{x})} \] Where \(V_k(\mathbf{x})\) is the volume of a hypersphere with radius \(r = d_k(\mathbf{x})\): \[ V_k(\mathbf{x}) = (d_k(\mathbf{x}))^d \cdot c_d \]

The constant \(c_d\) depends on the dimensionality:

  • \(c_1 = 2\) (Line)
  • \(c_2 = \pi\) (Circle)
  • \(c_3 = 4\pi/3\) (Sphere)
8.4

Nonparametric Classification

Nonparametric classification applies density estimation to predict class labels using Bayes' Rule:

\[ g_i(x) = \hat{p}(x|C_i) \hat{P}(C_i) \]

Kernel Classifier (Voting Mechanism)

When using a kernel estimator, each training instance \(x^t\) "votes" for its class \(C_i\). The weight of the vote depends on the distance between the query point \(x\) and the instance \(x^t\).

\[ g_i(x) = \frac{1}{N h^d} \sum_{t: x^t \in C_i} K\left(\frac{x - x^t}{h}\right) \] → The common factor \(1/(N h^d)\) can be ignored during maximization.

k-Nearest Neighbor (k-NN) Classifier

The k-NN classifier simplifies the posterior probability calculation by looking at the local neighborhood of \(k\) points:

\[ \hat{P}(C_i|x) = \frac{k_i}{k} \] → Where \(k_i\) is the number of neighbors belonging to class \(C_i\).
✦ The Decision Rule
Assign \(x\) to the class with the Majority Vote.
Tip: \(k\) is usually taken as an odd number to minimize ties.

The Special Case: k = 1

When \(k=1\), we have the Nearest Neighbor Classifier. This divides the input space into a Voronoi Tessellation—a set of regions where every point in a region is closer to its "generator" instance than to any other point.

8.5

Condensed Nearest Neighbor

The main drawback of nonparametric methods is that complexity is proportional to the training set size \(N\). Condensed Nearest Neighbor (CNN) aims to find a Consistent Subset \(\mathcal{Z} \subset \mathcal{X}\) such that using \(\mathcal{Z}\) for 1-NN classification results in zero training error on \(\mathcal{X}\).

✦ The Core Logic
Points deep inside class regions do not define the discriminant boundary; only points near the boundary are necessary for classification. CNN greedily selects these boundary points.

Hart's Greedy Algorithm

  1. Initialize \(\mathcal{Z}\) as an empty set.
  2. Pass through the training set \(\mathcal{X}\) in random order.
  3. For each \(x \in \mathcal{X}\), check if it is correctly classified by 1-NN using the current \(\mathcal{Z}\).
  4. If misclassified, add \(x\) to \(\mathcal{Z}\).
  5. Repeat the entire pass until no more points are added to \(\mathcal{Z}\).
Important Limitations
  • Order Dependency: Different random orders of \(\mathcal{X}\) result in different subsets \(\mathcal{Z}\).
  • NP-Complete: Finding the absolute minimal consistent subset is an NP-complete problem.

Augmented Error Function

CNN can be viewed as an optimization problem where we minimize error while penalizing the number of stored instances:

\[ \mathcal{E}(\mathcal{X}|\mathcal{Z}) + \lambda |\mathcal{Z}| \] → Where \(\lambda\) is the trade-off parameter between training error and model complexity.
8.6

Distance-Based Classification

Most classification algorithms can be recast as distance-based. The core idea is that the more similar the instances, the more likely they belong to the same class.

Distance measures across paradigms:

  • Parametric (Nearest Mean): Assign to class \(C_i\) if \(\lVert x - m_i \rVert\) is minimal.
  • Semiparametric (Mixture Models): Assign to \(C_i\) if the closest cluster center among all classes belongs to \(C_i\).
  • Nonparametric (k-NN): Use local distance to neighbors.

Distance Learning

Instead of using a fixed metric, we can learn a parameterized distance \(D(x, x^t | \theta)\). The most common form is the Mahalanobis Distance where we learn the matrix \(\mathbf{M}\):

\[ \mathcal{D}(\mathbf{x}, \mathbf{x}^t) = (\mathbf{x} - \mathbf{x}^t)^T \mathbf{M} (\mathbf{x} - \mathbf{x}^t) \]
✦ Link to Dimensionality Reduction
By factoring \(\mathbf{M} = \mathbf{L}^T \mathbf{L}\) where \(\mathbf{L}\) is \(k \times d\) (\(k < d\)), the Mahalanobis distance in the original space becomes the Euclidean distance in a new \(k\)-dimensional projected space.

Similarity-Based Representation

If we have a similarity score function \(s(x, x^t)\), we can represent any instance \(x\) as an \(N\)-dimensional vector of its similarity scores with all training instances:

\[ \mathbf{x}' = [s(x, x^1), s(x, x^2), \dots, s(x, x^N)]^T \] → This is also called the Empirical Kernel Map.

Discrete Data: Hamming Distance

For discrete/categorical features, we use the Hamming distance to count mismatching attributes:

\[ \mathcal{D}(\mathbf{x}, \mathbf{y}) = \sum_{j=1}^d H(x_j, y_j) \quad \text{where } H(a, b) = \begin{cases} 0 & \text{if } a=b \\ 1 & \text{if } a \neq b \end{cases} \]
8.7

Outlier Detection

An Outlier (novelty/anomaly) is an instance that is significantly different from others. Instead of two-class classification, this is often treated as One-Class Classification, where we model the "typical" instances and reject anything else as an anomaly.

✦ Robustness Note
Parametric models are not robust to outliers; a single extreme value can corrupt the estimated mean and covariance of a Gaussian. Nonparametric models are more robust because their estimates are local.

Local Outlier Factor (LOF)

LOF compares the denseness of the neighborhood of an instance \(x\) with the average denseness of the neighborhoods of its neighbors. Let \(N(x)\) be the set of \(k\)-nearest neighbors of \(x\).

\[ LOF(x) = \frac{1}{|N(x)|} \sum_{s \in N(x)} \frac{d_k(s)}{d_k(x)} \] → Where \(d_k(x)\) is the distance to the \(k\)-th nearest neighbor.
Interpretation
  • \(LOF(x) \approx 1\): The density of \(x\) is similar to its neighbors; it is a normal point.
  • \(LOF(x) \gg 1\): The neighbors are in a much denser region than \(x\); it is likely an outlier.
8.8

Nonparametric Regression: Smoothing Models

In regression, we assume \(r^t = g(x^t) + \epsilon\). The goal is to estimate \(g(x)\) by averaging response values in the neighborhood of \(x\). The estimator is called a Smoother and the estimate is called a Smooth.

✦ Regressogram
The regression equivalent of a histogram. We divide the space into bins and calculate the average \(r^t\) for each bin. Like the histogram, it suffers from discontinuities at bin boundaries.

8.8.1 Running Mean Smoother

Calculates a simple average of \(r^t\) values within a symmetric window \(h\) centered at \(x\). For noisy data, the median can be used instead of the mean for better robustness.

\[ \hat{g}(x) = \frac{\sum_{t=1}^N w\left(\frac{x-x^t}{h}\right) r^t}{\sum_{t=1}^N w\left(\frac{x-x^t}{h}\right)} \] → where \(w(u) = 1\) if \(|u| < 1/2\), else \(0\).

8.8.2 Kernel Smoother (Nadaraya-Watson)

Replaces the hard window with a smooth kernel \(K(\cdot)\), giving higher weight to points closer to the query point \(x\). This results in a continuous, differentiable smooth.

\[ \hat{g}(x) = \frac{\sum_{t=1}^N K\left(\frac{x-x^t}{h}\right) r^t}{\sum_{t=1}^N K\left(\frac{x-x^t}{h}\right)} \]

8.8.3 Running Line Smoother (LOESS)

The running mean suffers from bias at the boundaries. To fix this, we fit a local regression line instead of a constant mean, taking one more term in the Taylor expansion.

\[ E(a, b|x) = \sum_{t=1}^N w\left(\frac{x-x^t}{h}\right) [r^t - (a + b(x^t - x))]^2 \] → The estimate is the intercept: \(\hat{g}(x) = a\).

When kernel weighting is used to minimize this error, the method is known as LOESS (Locally Weighted Running Line Smoother).

9.1

Introduction

A Decision Tree is a hierarchical model for supervised learning that implements a divide-and-conquer strategy. It is a powerful nonparametric method where the input space is partitioned into local regions via a sequence of recursive splits.

✦ Why is it Nonparametric?
Unlike parametric models, the structure of a decision tree is not fixed a priori. Instead, the tree grows during learning, adding branches and leaves based on the complexity inherent in the training data.

Key Advantages

  • Interpretability: A tree can be easily converted into a set of IF-THEN rules, making it one of the most transparent machine learning models.
  • Search Efficiency: In the best case, with binary splits, a region among \(b\) possible regions can be found in just \(\log_2 b\) decisions.
  • Local Simplicity: A complex global function is broken down into a series of simple, local decisions at each node.
Tree Components
  • Internal Decision Nodes: Implement a test function \(f_m(x)\) with discrete outcomes labeling the branches.
  • Terminal Leaves: Store the final output—a class code for classification or a numeric value for regression.
9.2

Univariate Trees

In a Univariate Tree, each internal node $m$ uses only a single input dimension $x_j$ for its test function $f_m(x)$. For numeric data, this split is defined as \(x_j > w_{m0}\).

✦ Geometry: Axis-Aligned Splits
Because each test considers only one feature at a time, successive splits are orthogonal to each other. This divides the input space into axis-aligned hyperrectangles.

9.2.1 Classification Trees

A node is split if it is not "pure" (i.e., it contains instances of multiple classes). We choose the split that maximizes the drop in Impurity.

Common Impurity Measures \(\phi(p_1, p_2, \dots, p_K)\):
  • Entropy: \(I_m = -\sum_{i=1}^K p_{mi} \log_2 p_{mi}\)
  • Gini Index: \(I_m = 1 - \sum_{i=1}^K p_{mi}^2\)
  • Misclassification Error: \(I_m = 1 - \max_i p_{mi}\)
Exam Tip: Finding Split Points
For a numeric attribute, we don't need to check infinite points. It is sufficient to check positions halfway between adjacent points belonging to different classes.

9.2.2 Regression Trees

For regression, the impurity measure is replaced by Mean Square Error (MSE). The value stored in a leaf is the mean (or robust median) of the instances reaching that node.

\[ E_m = \frac{1}{N_m} \sum_{t \in \mathcal{X}_m} (r^t - g_m)^2 \] → Where \(g_m\) is the average of \(r^t\) in node \(m\).
Complexity Control
Tree growth is stopped (Prepruning) if:
  • The impurity/error drop is below a threshold (\(\theta_I\) or \(\theta_r\)).
  • The number of instances in a node falls below a certain percentage (e.g., 5%).
9.3

Pruning

Decision trees are prone to overfitting. Growing a tree until all leaves are pure often captures noise. Pruning simplifies the tree to improve generalization.

9.3.1 Prepruning (Early Stopping)

Stop growing the tree before it is full. A node is not split if:

  • The number of instances is too small (e.g., < 5% of training set).
  • The impurity drop is not significant.

Pro: Much faster. Con: May suffer from underfitting.

9.3.2 Postpruning

Grow the tree to its full depth (zero training error) and then backtrack to remove subtrees that cause overfitting. This is the only part of tree induction that allows backtracking.

The Pruning Set
To decide whether to prune, we use a separate Pruning Set (distinct from both training and validation sets). We replace a subtree with a single leaf if the error on the pruning set does not increase.

9.4

Rule Extraction from Trees

Decision trees are inherently interpretable because every path from the root to a leaf can be written as an IF-THEN rule.

✦ Logical Structure
  • Conjunction (AND): Each individual rule is a conjunction of the tests along its path.
  • Disjunction (OR): If multiple leaves lead to the same class, the class region is a union (OR) of those conjunctive rules.

Example Rule Base

From the hypothetical tree in the text, we can extract the following rules:

R1: IF (age > 38.5) AND (years-in-job > 2.5) THEN y = 0.8
R2: IF (age > 38.5) AND (years-in-job ≤ 2.5) THEN y = 0.6
R3: IF (age ≤ 38.5) AND (job-type = 'A') THEN y = 0.4
R4: IF (age ≤ 38.5) AND (job-type = 'B') THEN y = 0.3
R5: IF (age ≤ 38.5) AND (job-type = 'C') THEN y = 0.2
Knowledge Extraction & Support
Rules allow experts to verify the model. For each rule, we calculate Rule Support—the percentage of training data covered by that rule.

Rule Pruning

It is possible to prune a term from a rule (e.g., removing the 'age' condition from R3) if it doesn't decrease performance. Note: After pruning individual rules, they may no longer be representable as a tree.

9.5

Learning Rules from Data

Instead of converting a tree, we can learn rules directly using Sequential Covering (Separate-and-Conquer). While tree induction is breadth-first, rule induction is depth-first, generating one rule at a time.

The Ripper Algorithm (Outer Loop)
  1. Initialize \(RuleBase = \emptyset\).
  2. While positive examples remain in training set:
    • Grow: Add conditions to a new rule \(R\) to maximize Information Gain until it covers no negative examples.
    • Prune: Simplify \(R\) using a pruning set to maximize the rule value metric.
    • Add \(R\) to \(RuleBase\).
    • Remove: Delete all training instances covered by \(R\).
  3. Optimize the entire \(RuleBase\) using MDL (Minimum Description Length) criteria.

Growth & Pruning Metrics

To choose the best condition to add to a rule, Ripper uses FOIL Gain:

\[ Gain(R, R') = s \cdot \left[ \log_2 \frac{N'_+}{N'} - \log_2 \frac{N_+}{N} \right] \] → Where \(s\) is the number of true positives in \(R\) still covered by \(R'\).

To prune a rule, we maximize the Rule Value Metric on the pruning set:

\[ v = \frac{p - n}{p + n} \] → \(p\): True Positives, \(n\): False Positives.
Example: IF Father(y, x) AND Female(y) THEN Daughter(x, y)
14.1

Introduction to Kernel Machines

Kernel Machines, most notably Support Vector Machines (SVMs), represent a paradigm shift from traditional parametric models. They bridge the gap between global models (which use all data to fit a single boundary) and local models (like k-NN which use only neighbors).

✦ The Dual Representation
The core novelty of kernel machines is the Dual Representation. Instead of defining parameters (weights) in the feature space, the parameters are defined in terms of the training instances themselves. The discriminant function is a weighted sum of similarities to a subset of the training data.
Key Advantages
  • The Kernel Trick: We can work in highly complex, high-dimensional feature spaces without ever explicitly computing the mapping \(\phi(x)\). We only need the dot product \(K(x, x^t) = \phi(x)^T \phi(x^t)\).
  • Global Optimality: Training an SVM is a Convex Optimization problem. Unlike neural networks, it has a unique global minimum and no local minima.
  • Sparsity: Most of the parameters (\(\alpha_t\)) in the final solution are zero. Only the "critical" points—the Support Vectors—are stored for prediction.

Theoretical Foundation

We map the input \(x\) into a new, higher-dimensional space \(\phi(x)\). A linear boundary in this high-dimensional space corresponds to a nonlinear boundary in the original input space. The discriminant function takes the form:

\[ g(x) = \sum_{t=1}^N \alpha_t r^t K(x, x^t) + w_0 \] → where \(K(x, x^t)\) is the kernel function measuring similarity.
14.2

Optimal Separating Hyperplane

For a linearly separable dataset, we seek the hyperplane that maximizes the Margin (the distance between the boundary and the nearest instances). This is done by solving a constrained optimization problem.

1. The Primal Problem: Minimize: \[ L_p = \frac{1}{2} \|w\|^2 \] Subject to: \[ r^t (w^T x^t + w_0) \geq 1, \quad \forall t \]

Lagrangian Formulation

To solve the primal, we introduce Lagrange Multipliers (\(\alpha_t \geq 0\)):

\[ L_p = \frac{1}{2} \|w\|^2 - \sum_{t=1}^N \alpha_t \left[ r^t (w^T x^t + w_0) - 1 \right] \]
✦ Partial Derivatives & Weights
Taking the derivatives with respect to \(w\) and \(w_0\) and setting them to zero gives:
  • \( w = \sum_{t=1}^N \alpha_t r^t x^t \) (The weight vector is a linear combination of training points!)
  • \( \sum_{t=1}^N \alpha_t r^t = 0 \)

The Dual Problem

By substituting the values of \(w\) and \(w_0\) back into the Lagrangian, we get the Dual Optimization, which we maximize with respect to \(\alpha_t\):

\[ L_d = \sum_{t=1}^N \alpha_t - \frac{1}{2} \sum_{t} \sum_{s} \alpha_t \alpha_s r^t r^s (x^t)^T x^s \] Subject to: \[ \sum \alpha_t r^t = 0 \quad \text{and} \quad \alpha_t \geq 0 \]
Support Vectors & Sparsity
Most \(\alpha_t\) will be zero. Only those instances \(x^t\) where the constraint is exactly met (\(r^t(w^T x^t + w_0) = 1\)) have \(\alpha_t > 0\). These are the Support Vectors.
Calculating the Bias (w0)
Once we have \(\alpha_t\), we calculate \(w_0\) using any support vector \(x^t\) by solving: \[ r^t (w^T x^t + w_0) = 1 \]

Support Vectors
The training points \(x^t\) that satisfy the constraint with equality (\(r^t(w^T x^t + w_0) = 1\)) are the Support Vectors. They are the only points that "support" the boundary; removing other points wouldn't change the boundary.
14.3

The Nonseparable Case: Soft Margin Hyperplane

When data is not linearly separable, we introduce slack variables \(\xi^t \geq 0\) and minimize a combination of the margin width and the total error.

1. The Primal Objective: \[ \min L_p = \frac{1}{2} \|w\|^2 + C \sum_{t=1}^N \xi^t \] Subject to: \[ r^t (w^T x^t + w_0) \geq 1 - \xi^t \quad \text{and} \quad \xi^t \geq 0 \]

The Soft Lagrangian

We introduce multipliers \(\alpha_t \geq 0\) for the margin constraints and \(\mu_t \geq 0\) for the slack non-negativity:

\[ L_p = \frac{1}{2} \|w\|^2 + C \sum \xi^t - \sum \alpha_t \left[ r^t (w^T x^t + w_0) - (1 - \xi^t) \right] - \sum \mu_t \xi^t \]
✦ Deriving the Box Constraint
Taking the derivative with respect to slack \(\xi^t\): \[ \frac{\partial L_p}{\partial \xi^t} = C - \alpha_t - \mu_t = 0 \] Since \(\mu_t \geq 0\), this implies the Box Constraint: \[ 0 \leq \alpha_t \leq C \]

The Dual Soft Margin Problem

Substituting the derivatives back, we get a Dual identical to the separable case but with a bounded \(\alpha_t\):

Maximize: \[ L_d = \sum_{t=1}^N \alpha_t - \frac{1}{2} \sum_{t} \sum_{s} \alpha_t \alpha_s r^t r^s (x^t)^T x^s \] Subject to: \[ \sum \alpha_t r^t = 0 \quad \text{and} \quad \mathbf{0 \leq \alpha_t \leq C} \]
Types of Support Vectors
  • \(0 < \alpha_t < C\): The instance is on the margin (\(\xi^t = 0\)). These are used to calculate \(w_0\).
  • \(\alpha_t = C\): The instance is either inside the margin (\(0 < \xi^t < 1\)) or misclassified (\(\xi^t \geq 1\)).
14.4

v-SVM

The \(\nu\)-SVM formulation provides a more intuitive way to handle the trade-off between the margin and errors. In this model, the margin \(\rho\) is not fixed at 1 but is a variable to be optimized.

Primal Objective: \[ \min \frac{1}{2} \|w\|^2 - \nu \rho + \frac{1}{N} \sum_{t=1}^N \xi^t \] Subject to: \[ r^t (w^T x^t + w_0) \geq \rho - \xi^t, \quad \xi^t \geq 0, \quad \rho \geq 0 \]
✦ The v-Property (Exam Critical)
The parameter \(\nu \in (0, 1)\) satisfies two important properties:
  1. It is an upper bound on the fraction of margin errors.
  2. It is a lower bound on the fraction of Support Vectors.
Intuition: Selecting \(\nu = 0.05\) means you expect at most 5% training errors and at least 5% of your data will become Support Vectors.
The v Dual Constraints
The dual maximization for \(\nu\)-SVM is subject to:
  • \( \sum \alpha_t r^t = 0 \)
  • \( 0 \leq \alpha_t \leq \frac{1}{N} \)
  • \( \sum \alpha_t \geq \nu \)
14.5

The Kernel Trick

The Kernel Trick is the foundation of nonlinear SVMs. It allows us to find a linear decision boundary in a high-dimensional Feature Space \( \mathcal{F} \) without ever explicitly mapping the data points to that space.

Mathematical Derivation

  1. Mapping: We transform the input \(x\) into a feature space using a nonlinear function \(\phi(x)\).
  2. Linear Discriminant: In this new space, the boundary is: \[ g(x) = w^T \phi(x) + w_0 \]
  3. Dual Representation: From the optimization in 14.2, we know the weight vector is: \[ w = \sum_{t=1}^N \alpha_t r^t \phi(x^t) \]
  4. Substitution: Replacing \(w\) in the discriminant gives:
    \[ g(x) = \left( \sum_{t=1}^N \alpha_t r^t \phi(x^t) \right)^T \phi(x) + w_0 \] \[ g(x) = \sum_{t=1}^N \alpha_t r^t \langle \phi(x^t), \phi(x) \rangle + w_0 \]
✦ The Core Idea
We replace the dot product \(\langle \phi(x^t), \phi(x) \rangle\) with a Kernel Function \( K(x^t, x) \).
Implicit Mapping: We can compute the similarity in the high-dimensional space using only the coordinates in the original input space. This avoids the computational cost of direct mapping.
The Gram Matrix (K)
The optimization depends on the \(N \times N\) matrix of all pairwise kernels: \( K_{ts} = K(x^t, x^s) \). For the solution to be valid (Convex), the kernel must satisfy Mercer's Condition: it must be symmetric and positive semi-definite.
14.6

Vectorial Kernels

While most SVMs assume inputs are vectors in \(\mathbb{R}^d\), the kernel trick allows us to apply SVMs to non-vectorial data like sequences (DNA, text), graphs, or sets, provided we can define a valid similarity measure.

✦ Defining Similarity on Objects
For any two objects \(x\) and \(y\), a kernel measures their overlap in terms of shared substructures: \[ K(x, y) = \sum_{p \in \mathcal{P}} w_p \cdot I(p \in x) \cdot I(p \in y) \] → where \(p\) represents a substructure (like a substring or a subgraph) and \(I(\cdot)\) is an indicator function.

Common Examples

  • String Kernels: Used in bioinformatics and NLP. Similarity is based on the number of common substrings or motifs shared between two sequences.
  • Graph Kernels: Measures similarity between structured data (like chemical compounds) by counting common paths, walks, or subgraphs.
Empirical Kernel Map
If a direct kernel is difficult to define, we can use templates. We define \(M\) templates \(\{m_i\}_{i=1}^M\) and represent every object \(x\) as a vector of its scores to these templates: \[ \phi(x) = [s(x, m_1), s(x, m_2), \dots, s(x, m_M)]^T \]
14.7

Defining Kernels

The choice of kernel defines the geometry of the decision boundary. Each kernel has unique properties and hyperparameters that must be carefully tuned.

1. Polynomial Kernels
\[ K(x, x^t) = (\mathbf{x}^T \mathbf{x}^t + 1)^q \]
  • Linear (q=1): Equivalent to the standard dot product.
  • Quadratic (q=2): Maps the input into a space that includes all original features, their squares (\(x_i^2\)), and all cross-products (\(x_i x_j\)).
  • Geometric Interpretation: Allows for boundaries that are conic sections (ellipses, parabolas, hyperbolas).
2. Radial Basis Function (RBF) / Gaussian
\[ K(x, x^t) = \exp\left( -\frac{\|\mathbf{x} - \mathbf{x}^t\|^2}{2\sigma^2} \right) \]
  • Localized Similarity: The value is 1 if \(x = x^t\) and drops to 0 as the distance increases. It acts as a "smooth" version of k-NN.
  • The Spread (\(\sigma\)):
    → Small \(\sigma\): High influence only very close to the point (Risk of Overfitting).
    → Large \(\sigma\): Wide influence, creating a smoother boundary (Risk of Underfitting).
  • Infinite Dimensions: Theoretically, the RBF kernel maps data into an infinite-dimensional feature space.
3. Sigmoid Kernel
\[ K(x, x^t) = \tanh(\eta \mathbf{x}^T \mathbf{x}^t + \nu) \]

This kernel allows the SVM to act like a Multi-layer Perceptron (MLP). However, it only satisfies Mercer's condition for certain values of \(\eta\) and \(\nu\).

✦ Kernel Normalization
If the data varies significantly in scale, we can normalize the kernel to ensure \(K(x, x) = 1\): \[ K'(x, y) = \frac{K(x, y)}{\sqrt{K(x, x)K(y, y)}} \]
14.8

Multiple Kernel Learning (MKL)

Instead of choosing a single fixed kernel, Multiple Kernel Learning (MKL) allows us to use a combination of kernels. This is particularly useful when data comes from multiple sources or has diverse feature types.

Combined Kernel: \[ K(x, y) = \sum_{i=1}^m \beta_i K_i(x, y) \] → where \(K_i\) are basis kernels and \(\beta_i\) are their respective weights.
✦ Types of Combinations
  • Fixed: Weights are set manually (e.g., \(\beta_i = 1/m\)).
  • Conic Combination: \(\beta_i \geq 0\). This ensures the combined kernel is positive semi-definite.
  • Convex Combination: \(\beta_i \geq 0\) and \(\sum \beta_i = 1\). This prevents the kernel values from scaling infinitely.

Why use MKL?

  1. Multimodal Data: If your data has both images and text, you can use an RBF kernel for the images and a String kernel for the text, then combine them.
  2. Feature Grouping: Different kernels can be applied to different subsets of features.
  3. Automated Selection: Instead of doing cross-validation to pick "the best" kernel, the optimization algorithm learns the best weights \(\beta_i\).
Optimization Note
In MKL, we solve for two sets of variables: the support vector weights \(\alpha_t\) and the kernel weights \(\beta_i\). This is typically solved using an iterative approach.
14.10

Kernel Machines for Regression (SVR)

Support Vector Regression (SVR) uses the same principles as SVM but for predicting continuous values. Unlike standard regression, it aims to find a function where most data points fall within an \(\epsilon\)-tube.

✦ \(\epsilon\)-sensitive Loss Function
Errors smaller than \(\epsilon\) are ignored. This is key to achieving a sparse solution: \[ e_\epsilon(r^t, f(x^t)) = \begin{cases} 0 & \text{if } |r^t - f(x^t)| \leq \epsilon \\ |r^t - f(x^t)| - \epsilon & \text{otherwise} \end{cases} \]

The SVR Optimization

We introduce two sets of slack variables, \(\xi^t\) and \(\hat{\xi}^t\), for points that fall above and below the \(\epsilon\)-tube respectively.

Primal Objective: \[ \min \frac{1}{2} \|w\|^2 + C \sum_{t=1}^N (\xi^t + \hat{\xi}^t) \] Subject to: \[ r^t - (w^T \phi(x^t) + w_0) \leq \epsilon + \xi^t \] \[ (w^T \phi(x^t) + w_0) - r^t \leq \epsilon + \hat{\xi}^t \] \[ \xi^t, \hat{\xi}^t \geq 0 \]
Geometric Interpretation

The thick line is the regression line, and the dashed lines are the boundaries of the tube. Only points outside or on the boundary of the tube have non-zero coefficients (\(\alpha_t\)) and act as Support Vectors.

The SVR Dual Problem
The prediction for a new point \(x\) is given by: \[ f(x) = \sum_{t=1}^N (\alpha_t^* - \alpha_t) K(x^t, x) + w_0 \] → where \(\alpha_t^*\) and \(\alpha_t\) are the Lagrange multipliers from the optimization.
14.12

One-Class Kernel Machines

One-class SVMs are used for Novelty Detection or Outlier Detection. The goal is to define a boundary that encloses the region of the input space where most of the data points lie.

✦ Schölkopf's Approach: Separation from Origin
In this method, we map the data to a feature space and try to separate it from the origin with maximum margin using a hyperplane.
\[ \min \frac{1}{2} \|w\|^2 - \rho + \frac{1}{\nu N} \sum_{t=1}^N \xi^t \] Subject to: \( w^T \phi(x^t) \geq \rho - \xi^t \) and \( \xi^t \geq 0 \)

Support Vector Data Description (SVDD)

An alternative approach (Tax and Duin) is to find the smallest possible sphere that encloses all or most of the training points.

Sphere Objective: \[ \min R^2 + C \sum_{t=1}^N \xi^t \] Subject to: \( \|\phi(x^t) - a\|^2 \leq R^2 + \xi^t \)
The One-Class Dual
\[ \min \frac{1}{2} \sum_{t} \sum_{s} \alpha_t \alpha_s K(x^t, x^s) \] Subject to: \[ 0 \leq \alpha_t \leq \frac{1}{\nu N} \quad \text{and} \quad \sum \alpha_t = 1 \]
14.14

Kernel PCA

Standard PCA is linear. Kernel PCA performs Principal Component Analysis in the high-dimensional feature space, allowing for Nonlinear Dimensionality Reduction.

Kernel Eigenvalue Problem: \[ K \mathbf{a}_i = N \lambda_i \mathbf{a}_i \] → where \(K\) is the \(N \times N\) kernel matrix and \(\mathbf{a}_i\) is the \(i\)-th eigenvector.
✦ Projecting to Principal Components
The projection of a new point \(x\) onto the \(i\)-th principal component is: \[ y_i(x) = \sum_{t=1}^N a_{it} K(x^t, x) \]
Computational Significance
Kernel PCA allows us to extract nonlinear features without ever knowing the mapping \(\phi(x)\). It is highly effective for datasets where classes are separated by complex, curved manifolds.

Large Margin Nearest Neighbor (14.13)

Learns a distance metric to improve k-NN classification by pulling "target neighbors" closer and pushing "imposters" (different class neighbors) away.

Kernel PCA (14.14)

Performs Principal Component Analysis in the high-dimensional feature space defined by a kernel. This allows for **Nonlinear Dimensionality Reduction**.
