## Facts

- Built a reusable, layered verification environment (generator, driver, monitor, scoreboard) as independent SystemVerilog classes communicating via mailboxes, run concurrently via fork/join_none, around a 4-bit x 4-bit combinational multiplier DUT.
- Combined dist-weighted constrained-random stimulus with directed corner-case tests to guarantee every functional-coverage cross-bin is hit regardless of random luck.
- Self-checked against an independent reference model in the scoreboard; achieved 100% functional coverage.
