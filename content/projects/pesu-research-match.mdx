## Facts

- Built a hybrid semantic search engine combining dense vector retrieval (BGE-Large) and BM25 lexical search for faculty recommendation / matching.
- Integrated a local LLM (Qwen2.5-0.5B) to generate personalized match explanations; deployed via Docker on Hugging Face Spaces.
