7.1

Introduction

In parametric density estimation, we assume the data is drawn from a single known distribution (like a Gaussian). However, assuming a rigid parametric model can be a significant source of bias if the data naturally forms multiple subgroups.

✦ The Semiparametric Approach
When a single distribution is untenable, we use a Semiparametric approach. This relaxes the rigid assumption by allowing a mixture of distributions to represent the sample.

The Need for Multiple Prototypes

A single Gaussian assumes data forms one group. In practice, many classes are disjunctions of multiple groups:

Example: Digit 7 OCR

The digit '7' can be written in two distinct styles:

  • American Style: '7' (simple stroke)
  • European Style: '7' with a horizontal bar in the middle.

To be statistically correct, the class '7' should be modeled as a mixture of two Gaussians—one for each prototype style.

Similar examples exist in Speech Recognition, where a single word has different "prototypes" due to variations in accent, gender, and age.

While semiparametric methods assume a parametric model for each group, nonparametric methods (Chapter 8) are used when no structure is applicable at all. In this chapter, we focus on unsupervised learning to find these hidden groups.

7.2

Mixture Densities

A Mixture Density is a weighted sum of several component densities. This allows for representing data that comes from multiple distinct sources.

\[ p(x) = \sum_{i=1}^k p(x|G_i) P(G_i) \] → where \(G_i\) are the mixture components (clusters).

Key Components:

  • \(p(x|G_i)\): Component densities (e.g., multivariate Gaussians \(N(\mu_i, \Sigma_i)\)).
  • \(P(G_i)\): Mixture proportions (priors), where \(\sum P(G_i) = 1\).
  • \(k\): The number of components (a hyperparameter that must be specified).
✦ Supervised vs. Unsupervised Learning

Supervised: Labels are known. We know which instance belongs to which component. Parameter estimation is a simple Maximum Likelihood problem.

Unsupervised (Clustering): Labels are hidden. We don't know which \(x^t\) comes from which component \(G_i\). We must estimate both the labels and the parameters.

7.3

k-Means Clustering

The k-Means algorithm is a widely used iterative method for finding groups in data. In the context of signal processing, it is used for Vector Quantization—mapping a continuous space to a finite set of reference vectors.

Example: Color Quantization

Reducing an image from 24-bit color (16 million colors) to 8-bit (256 colors). We find the 256 colors (codebook) that best represent the original distribution of pixels.

Mathematical Objective

The goal is to minimize the Total Reconstruction Error (also called distortion):

\[ E(\{m_i\}_{i=1}^k | X) = \sum_{t} \sum_{i} b_i^t \|x^t - m_i\|^2 \] where \(b_i^t = 1\) if \(\|x^t - m_i\| = \min_j \|x^t - m_j\|\), and 0 otherwise.
✦ The k-Means Algorithm
  1. Initialize: Start with \(k\) centers \(m_i\) (randomly or via heuristics).
  2. Assignment Step: For each \(x^t\), find the closest center \(m_i\) and set \(b_i^t = 1\).
  3. Update Step: Recalculate each center as the mean of instances assigned to it: \[ m_i = \frac{\sum_t b_i^t x^t}{\sum_t b_i^t} \]
  4. Repeat: Iterate steps 2 and 3 until the centers \(m_i\) stabilize.

Initialization Strategies

  • Random Selection: Pick \(k\) instances from the training set as initial centers.
  • Mean Perturbation: Start with the global mean and add small random vectors to create \(k\) distinct centers.
  • PC Partitioning: Divide the range of the principal component into \(k\) equal intervals and take the mean of each.
Optimization Note
k-Means is a local search procedure. The final result depends heavily on the initial centers. It is common to run the algorithm multiple times with different initializations.
7.4

Expectation-Maximization (EM) Algorithm

The EM Algorithm is a general framework for Maximum Likelihood estimation in the presence of Hidden Variables (latent variables). In clustering, these hidden variables indicate which component generated which data point.

Log Likelihood: \[ \mathcal{L}(\Phi|X) = \sum_{t} \log \sum_{i=1}^k P(G_i) p(x^t|G_i) \]

The Two Steps of EM

1. E-Step (Expectation)
Calculate the Responsibilities \(h_i^t\). This is the posterior probability that instance \(x^t\) belongs to component \(G_i\): \[ h_i^t = E[z_i^t | x^t, \Phi^l] = P(G_i | x^t, \Phi^l) = \frac{p(x^t | G_i) P(G_i)}{\sum_j p(x^t | G_j) P(G_j)} \]
2. M-Step (Maximization)
Update the parameters \(\Phi\) to maximize the expected likelihood using the responsibilities found in the E-step:
  • Priors: \(\hat{P}(G_i) = \frac{\sum_t h_i^t}{N}\)
  • Means: \(\hat{\mu}_i = \frac{\sum_t h_i^t x^t}{\sum_t h_i^t}\)
  • Covariances: \(\hat{\Sigma}_i = \frac{\sum_t h_i^t (x^t - \hat{\mu}_i)(x^t - \hat{\mu}_i)^T}{\sum_t h_i^t}\)

EM vs. k-Means

k-Means is a special case of EM for Gaussian mixtures where:

  • All components have equal priors.
  • All components have equal, isotropic covariances.
  • The assignment is "hard" (\(h_i^t\) is either 0 or 1), whereas EM uses "soft" assignments.
7.5

Mixtures of Latent Variable Models

In high-dimensional spaces, using full covariance matrices for each mixture component can lead to Overfitting due to the massive number of parameters. Conversely, diagonal matrices might ignore crucial correlations.

✦ The Solution: Local Dimensionality Reduction
Instead of modeling the full covariance, we perform dimensionality reduction within each cluster. This captures correlations while keeping the number of free parameters manageable.

Mixture of Factor Analyzers (MFA)

Each cluster \(G_i\) is modeled using a separate Factor Analysis model:

\[ p(x|G_i) = N(\mu_i, V_i V_i^T + \Psi_i) \] → where \(V_i\) are the factor loadings and \(\Psi_i\) are the specific variances for cluster \(i\).

Mixtures of Probabilistic PCA

Similar to MFA, but specifically using Principal Component Analysis within each group. This is called Mixtures of Probabilistic PC Analyzers.

Coupled Learning
The EM algorithm couples clustering and dimensionality reduction. An instance \(x^t\) contributes to the calculation of the latent variables of all groups, weighted by its responsibility \(h_i^t\).
7.6

Supervised Learning after Clustering

Clustering can be used as a preprocessing stage for supervised learning. We map the data from the original \(d\)-dimensional space to a new \(k\)-dimensional space where the dimensions are the responsibilities \(h_i\).

✦ Local vs. Distributed Representation
  • Distributed (e.g., PCA): Few new dimensions, but all contribute to the representation of an instance (all values are non-zero).
  • Local (Clustering): Many new dimensions, but only one (hard assignment) or a few (soft assignment) are non-zero.

Mixture of Mixtures

In classification, we can model each class density as a mixture model itself. This is useful when a class is composed of several distinct prototypes:

\[ p(x|C_i) = \sum_{j=1}^{k_i} p(x|G_{ij}) P(G_{ij}) \] → where \(G_{ij}\) is component \(j\) of class \(i\).
Advantage of Unsupervised Preprocessing

Labeling data is expensive. We can use a large amount of unlabeled data for the unsupervised clustering stage (learning "what normally happens") and then use a smaller amount of labeled data for the supervised stage (learning "what it means").

7.7

Spectral Clustering

Spectral Clustering first maps data to a new space where clusters are more apparent and then performs clustering (like k-means) in that new space. It uses the Graph Laplacian to preserve local neighborhood structure.

The Graph Laplacian

We define a similarity matrix \(B\) and a diagonal degree matrix \(D\) where \(D_{ii} = \sum_j B_{ij}\). The unnormalized Laplacian is:

\[ L = D - B \]
✦ Normalized Laplacians
Normalization often leads to better clustering performance:
  • Random Walk: \( L_{rw} = I - D^{-1}B \)
  • Symmetric: \( L_{sym} = I - D^{-1/2} B D^{-1/2} \)

The Algorithm Process

  1. Local Neighborhood: Define a neighborhood for each point (e.g., k-nearest neighbors).
  2. Similarity: Compute pairwise similarities \(B_{ij}\) (e.g., using a Gaussian kernel) for neighbors, and set others to 0.
  3. Embedding: Use the eigenvectors of the Laplacian to map data to a new space (Feature Embedding).
  4. Clustering: Run k-means in this new space.
Why it works
Unlike PCA which preserves global variance, Laplacian eigenmaps preserve local similarities. Instances that are nearby in the original space (same cluster) will be placed very close in the new space, while those in different clusters will be pushed far apart.
7.8

Hierarchical Clustering

Hierarchical Clustering does not require a predefined number of clusters. Instead, it builds a tree-like hierarchy of clusters based on pairwise similarities.

✦ Two Directions
  • Agglomerative (Bottom-up): Starts with each instance in its own cluster and merges the two closest clusters iteratively.
  • Divisive (Top-down): Starts with one giant cluster and recursively splits it into smaller ones.

Linkage Methods (Merging Criteria)

How we define the "distance" between two groups of instances determines the shape of the clusters:

  • Single-Link: The distance between the closest pair of elements (one from each group).
    → Risk: "Chaining effect" where clusters become elongated.
  • Complete-Link: The distance between the farthest pair of elements.
    → Result: Produces compact, spherical clusters.
  • Average-Link: The average distance between all possible pairs.
  • Centroid-Link: The distance between the means (centroids) of the groups.
The Dendrogram

A visualization of the merge sequence. The leaves are instances, and the height of the branches indicates the distance at which clusters were merged. Cutting the tree at height \(h\) yields the desired clusters.

7.9

Choosing the Number of Clusters

Since \(k\) is a complexity parameter, choosing it correctly is critical. "Meaningless" groups can be forced onto data if \(k\) is incorrect.

✦ The Elbow Method
Plot the Reconstruction Error (or log likelihood) as a function of \(k\). As \(k\) increases, error decreases. The "elbow" is the point where the rate of decrease drops significantly, suggesting the natural number of clusters.

Other Heuristics:

  • Application Constraints: (e.g., color palette size).
  • Visualization: Plotting data in 2D using PCA to spot natural gaps.
  • Incremental Splitting: Start with \(k=1\) and split clusters until a maximum allowed error threshold is met.
  • Domain Validation: Checking if clusters represent meaningful real-world segments (e.g., customer archetypes).
6.1

Introduction (Dim. Reduction)

Dimensionality Reduction is a critical preprocessing step. While ideally a learner should handle irrelevant features, reducing dimensions separately offers several advantages.

✦ Why Reduce Dimensionality?
  • Efficiency: Lower memory and computational cost during both training and testing.
  • Robustness: Simpler models are less prone to Overfitting on small datasets (lower variance).
  • Interpretability: Finding Latent Factors allows for better understanding of the underlying process.
  • Visualization: Mapping data to 2D or 3D for visual inspection of structure and outliers.

Selection vs. Extraction

There are two primary paradigms for reducing dimensions:

  • Feature Selection: We find a subset of \(k\) original dimensions and discard the remaining \((d-k)\). This preserves the physical meaning of the features.
  • Feature Extraction: We find a new set of \(k\) dimensions that are linear or nonlinear combinations of the original dimensions (e.g., PCA, LDA).
6.3

Principal Component Analysis (PCA)

PCA is an unsupervised linear projection method that seeks to find a new coordinate system such that the variance of the projected data is maximized. It reduces dimensionality by discarding directions with low variance.

The Eigenvalue Problem: \[ \Sigma \mathbf{w}_i = \lambda_i \mathbf{w}_i \] → where \(\Sigma\) is the covariance matrix, \(\mathbf{w}_i\) are eigenvectors (PCs), and \(\lambda_i\) are eigenvalues (variance).

Key Mathematical Properties:

  • Maximizing Variance: The first PC (\(w_1\)) is the direction of maximum spread. Subsequent PCs (\(w_2, \dots\)) maximize remaining variance while being orthogonal to previous ones.
  • Proportion of Variance Explained: For \(k\) components: \[ \frac{\sum_{i=1}^k \lambda_i}{\sum_{i=1}^d \lambda_i} \]
  • Uncorrelated Features: After projection, the new variables \(z_i\) are uncorrelated (Covariance matrix of \(Z\) is diagonal).
✦ Choosing k (Scree Graph)
The Scree Graph plots eigenvalues in descending order. We typically look for the "elbow"—the point where the variance contribution of additional components becomes negligible. Alternatively, we keep enough PCs to explain a fixed percentage (e.g., 90%) of total variance.
Reconstruction & Error
PCA minimizes the Reconstruction Error: the squared distance between the original point \(x\) and its projection back from the \(k\)-dimensional space. \[ \text{Error} = \sum_t \|x^t - \hat{x}^t\|^2 \]
Importance of Normalization

If input dimensions have widely different scales (e.g., age in years vs. income in thousands), the dimension with the larger scale will dominate the variance. Standardizing data to zero mean and unit variance is crucial before applying PCA.

6.6

SVD & Matrix Factorization

Singular Value Decomposition (SVD) is a powerful matrix decomposition technique that works for any rectangular \(N \times d\) matrix.

\[ X = V \Lambda W^T \] → where \(V\) contains eigenvectors of \(XX^T\), \(W\) contains eigenvectors of \(X^T X\), and \(\Lambda\) contains singular values.

Matrix Factorization (\(X \approx FG\))

We can represent a large matrix as the product of two smaller matrices, capturing the latent structure of the data:

  • \(F\) (\(N \times k\)): Defines data instances in terms of hidden factors.
  • \(G\) (\(k \times d\)): Defines factors in terms of the original attributes.
Example: Retail Consumer Data

A customer-product purchase matrix can be factored into \(k\) hidden factors like "household size", "income level", or "lifestyle preference". This explains purchases not as random events, but as outcomes of these latent variables.

6.8

Linear Discriminant Analysis (LDA)

LDA is a supervised method that uses class information to find directions that maximize the separation between different classes.

✦ Fisher’s Linear Discriminant
We seek a direction \(\mathbf{w}\) that maximizes the ratio of Between-class scatter (\(S_B\)) to Within-class scatter (\(S_W\)): \[ J(\mathbf{w}) = \frac{\mathbf{w}^T S_B \mathbf{w}}{\mathbf{w}^T S_W \mathbf{w}} \]

Scatter Matrices:

  • \(S_B\) (Between-class): Measures the distance between class means. \[ S_B = \sum_{i=1}^K N_i (\mathbf{m}_i - \mathbf{m})(\mathbf{m}_i - \mathbf{m})^T \]
  • \(S_W\) (Within-class): Measures the spread of data within each class. \[ S_W = \sum_{i=1}^K S_i \]
PCA vs. LDA

PCA: Unsupervised. Finds directions of maximum variance for the entire data, regardless of class.

LDA: Supervised. Specifically seeks directions that make classes separable.

Dimensionality Constraint: For \(K\) classes, LDA can find at most \(K-1\) discriminative directions.
